syntax:-
useEffect(function(){
    console.log('hari boLL")
},[])-> dependency array ,if i pass any state to this then whenever that state will change then this useeffect will also run , if it is kept empty then it runs only once ,and if it is not mentioned only then it runs as many times the react render occurs
